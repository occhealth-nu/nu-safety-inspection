# คู่มือผู้รับผิดชอบแก้ไข (และผู้ตรวจยืนยัน / ผู้บริหาร)

## ผู้รับผิดชอบแก้ไข

### รับงาน
1. เมื่อได้รับมอบหมาย จะมีแจ้งเตือน 🔔 (และอีเมล หากระบบตั้งค่า SMTP แล้ว)
2. เมนู **ติดตามแก้ไข** → แท็บ **งานของฉัน** → เปิดรายการ
3. อ่านรายละเอียด ตำแหน่ง ภาพก่อนแก้ไข มาตรการเบื้องต้น และกำหนดแล้วเสร็จ
4. กด **รับงาน / เริ่มแก้ไข** → สถานะ “กำลังแก้ไข”

### ระหว่างแก้ไข
- **รายงานความคืบหน้า**: บันทึกสิ่งที่ทำ/อุปสรรค และร้อยละ (ผู้ดูแลเห็นในประวัติ)
- ต้องให้หน่วยงานอื่นช่วย: **ส่งใบงาน** → พิมพ์/บันทึก PDF ส่งต่อ (ระบบยังไม่เชื่อม API ภายนอก)

### ส่งผลแก้ไข
1. **แนบภาพหลังแก้ไข** (ถ่ายมุมเดียวกับภาพก่อนแก้ไขถ้าทำได้)
   - ถ่ายภาพไม่ได้: กรอก “เหตุผลที่ไม่แนบภาพ”
2. กรอก **สรุปการแก้ไข** → **ส่งผลแก้ไขให้ตรวจยืนยัน** → สถานะ “รอตรวจยืนยัน”
3. คุณ **ไม่สามารถยืนยัน/ปิดงานของตนเองได้** (ระบบบังคับแยกหน้าที่)

### ถูกส่งกลับ
- ได้รับแจ้งเตือนพร้อมเหตุผล สถานะกลับเป็น “กำลังแก้ไข” และนับจำนวนครั้งที่ส่งกลับ
- ต้องแนบ **ภาพหลังแก้ไขใหม่** (ภาพก่อนการส่งกลับไม่นับ) แล้วส่งผลอีกครั้ง

### กำหนดเวลา
- ระบบเตือนก่อนครบกำหนด (ค่าเริ่มต้น 3 วัน) และเมื่อเกินกำหนด; เกินกำหนดนานจะยกระดับถึงผู้ดูแลหน่วยงาน/ส่วนกลาง

## ผู้ตรวจยืนยัน
1. แจ้งเตือน “มีผลการแก้ไขรอตรวจยืนยัน” หรือ **ติดตามแก้ไข › รอตรวจยืนยัน**
2. เปรียบเทียบภาพก่อน–หลัง อ่านประวัติ (ควรตรวจหน้างานหากเป็นข้อบกพร่องเร่งด่วน)
3. **ผ่าน — ปิดงาน** หรือ **ส่งกลับแก้ไข** (ต้องระบุเหตุผล)
4. งานจะปิดได้ด้วยการตรวจยืนยันเท่านั้น — ไม่มีปุ่มหรือช่องทางอื่นที่ปิดงานได้

## ผู้บริหาร / คณะกรรมการความปลอดภัย
- **แดชบอร์ด**: ภาพรวมตามขอบเขตสิทธิ์ เลือกหน่วยงาน/อาคาร/หมวด/ช่วงเวลา (รวมปีงบประมาณ) คลิกตัวเลขเพื่อดูรายการต้นทาง
- **รายงาน**: ดาวน์โหลด Excel หรือพิมพ์ PDF — สรุปรายเดือน, งานค้าง, ผลการแก้ไข
- บทบาทนี้อ่านอย่างเดียว ไม่สามารถแก้ไขข้อมูลการตรวจ

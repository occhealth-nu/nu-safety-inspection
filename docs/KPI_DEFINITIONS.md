# นิยามตัวชี้วัด (KPI) — Dashboard

ทุกตัวชี้วัดคำนวณในฐานข้อมูล (`public.dashboard_kpis`) แบบ security invoker จึง **นับเฉพาะข้อมูลที่ผู้ดูมีสิทธิ์** และใช้ตัวกรองเดียวกัน: หน่วยงาน (รวมหน่วยงานย่อย), อาคาร, หมวดการตรวจ, ผู้รับผิดชอบ/ผู้ตรวจ, ช่วงเวลา `[from, to]`
“วันนี้” และวันที่ของ timestamp ตีความตามเวลา Asia/Bangkok

| KPI | สูตร | ตัวหาร / หมายเหตุ |
|---|---|---|
| จุดตรวจ/อุปกรณ์ที่ใช้งานอยู่ | `count(assets where status = 'active')` | สแนปช็อตปัจจุบัน ไม่ขึ้นกับช่วงเวลา — **ไม่ใช้เป็นตัวหารของความครอบคลุม** |
| งานตรวจที่ถึงกำหนดในช่วงเวลา (Due) | `count(tasks where due_on ∈ [from,to] and status ≠ cancelled)` | ฐานของ KPI การตรวจทั้งหมด |
| ตรวจแล้ว (Done) | Due ที่ `status = completed` | รวมงานที่ส่งช้า (แสดงแยก “ส่งช้า” = completed_at (เวลาไทย) > due_on) |
| **ความครอบคลุมการตรวจ** | `Done ÷ Due × 100` | ตัวหาร = **งานตรวจที่ถึงกำหนด** (ไม่ใช่จำนวนอุปกรณ์) ; Due = 0 → แสดง “—” |
| ยังไม่ตรวจ | `Due − Done` | = ยังไม่ถึงกำหนด + รอตรวจ + เกินกำหนด |
| งานตรวจเกินกำหนด | Due ที่ยังไม่ส่งผล และ `due_on < วันนี้` | |
| สถานะการตรวจ | ยังไม่ถึงกำหนด: `period_start > วันนี้` · รอตรวจ: `period_start ≤ วันนี้ ≤ due_on` · ตรวจแล้ว · เกินกำหนด | ทั้งสี่สถานะรวมกัน = Due |
| ผลตรวจรายข้อ | นับคำตอบของผลตรวจที่ **ส่งในช่วงเวลา**: ผ่าน / ไม่ผ่าน (พบข้อบกพร่อง) / ไม่เกี่ยวข้อง | |
| อัตราผ่าน | `ผ่าน ÷ (ผ่าน + ไม่ผ่าน) × 100` | **ข้อ “ไม่เกี่ยวข้อง” ไม่นับในตัวหาร** (คะแนนรายครั้งใช้สูตรเดียวกัน) |
| ข้อบกพร่องที่ยังเปิดอยู่ | `count(findings where status ≠ closed)` | สแนปช็อตปัจจุบัน ไม่ขึ้นกับช่วงเวลา |
| ข้อบกพร่องเร่งด่วนที่ยังเปิด | ยังไม่ปิด และ `severity ∈ {high, critical}` | |
| สถานะการแก้ไข | รอแก้ไข = `open + assigned` · กำลังแก้ไข = `in_progress` · รอตรวจยืนยัน = `pending_verification` · ปิดงาน | ปิดงานบน Dashboard นับเฉพาะที่ปิดในช่วงเวลา |
| งานแก้ไขเกินกำหนด | `status ∈ {assigned, in_progress}` และ `due_on < วันนี้` | งานที่ส่งตรวจยืนยันแล้วไม่นับ (ผู้รับผิดชอบทำส่วนของตนแล้ว) |
| **ร้อยละการปิดงานภายในกำหนด** | `count(closed_at(ไทย) ≤ due_on) ÷ count(ปิดงานในช่วงเวลา และมี due_on) × 100` | ตัวหาร = งานที่ **ปิดในช่วงเวลา** และมีกำหนดเสร็จ |
| ข้อบกพร่องเกิดซ้ำ | ข้อบกพร่องที่ `recurrence_of` ไม่ว่าง (จุดตรวจเดิม หัวข้อเดิม ภายใน 365 วัน) | |

## ตารางตรวจรายปี (ม.ค.–ธ.ค.)

`public.dashboard_annual(year, group)` — แต่ละช่อง = **ตรวจแล้ว / ถึงกำหนด** ของงานที่ `due_on` อยู่ในเดือนนั้น
หนึ่งเดือนมีหลายงาน (เช่น รายสัปดาห์) จะแสดงเป็นจำนวน เช่น `3/4` สัญลักษณ์: ✓ ครบ, ! มีงานเกินกำหนด, ไม่มีสัญลักษณ์ = อยู่ในรอบ/ยังไม่ถึงรอบ (ใช้ข้อความ+ไอคอนคู่กับสี)

# คู่มือติดตั้งระบบฉบับสมบูรณ์ — NU Safety Inspection (v1.0)

คู่มือเดียวที่ครอบคลุมการติดตั้งทั้งหมด ตั้งแต่ฐานข้อมูล การเข้าสู่ระบบด้วย Google เว็บบน Vercel ไปจนถึง Google Sheets สำหรับจัดการข้อมูล และการตรวจรับระบบ

**ใช้ไฟล์จากชุด `NU-Safety-Complete-v1.0.zip` เท่านั้น** ชุดก่อนหน้า (Deploy, Install, AppsScript) ถูกรวมไว้ในชุดนี้แล้ว ให้ลบหรือย้ายชุดเก่าในเครื่องออกไปก่อนเริ่ม

### วิธีรันไฟล์ .sql (ใช้ทุกครั้ง)

1. https://supabase.com/dashboard → เลือกโปรเจกต์ → เมนูซ้าย **SQL Editor**
2. กด **+ New query** ทุกครั้งที่เริ่มไฟล์ใหม่
3. เปิดไฟล์ .sql ด้วย Notepad แล้วกด **Ctrl+A** และ **Ctrl+C**
4. คลิกในช่องเขียนของ Supabase กด **Ctrl+A** แล้ว **Ctrl+V**
5. กด **Run** (Ctrl+Enter) ถ้ามีหน้าต่างเตือน ให้กด **Run this query**
6. ตรวจผลให้ตรงกับตารางในคู่มือก่อนไปไฟล์ถัดไป

> ข้อความ NOTICE สีเทา เป็นเรื่องปกติ · ข้อความ ERROR สีแดง ให้หยุด แล้วดูส่วนที่ 11

## ส่วนที่ 4 — ตั้งค่าการเข้าสู่ระบบ (Supabase + Google)

### 4.1 URL ของเว็บ
Supabase → **Authentication → URL Configuration**

* **Site URL:** `https://nu-safety-inspection.vercel.app` (ไม่มี / ท้าย)
* **Redirect URLs:** มี `https://nu-safety-inspection.vercel.app/**`
* กด **Save**

### 4.2 ผู้ให้บริการเข้าสู่ระบบ
Supabase → **Authentication → Sign In / Providers**

* **Google:** ต้องเป็น **Enabled** และมี Client ID กับ Client Secret แล้ว
* **Allow new users to sign up:** ⚠️ **ต้องเปิด (ON)**
    * การเข้าด้วย Google ครั้งแรกของผู้ใช้ที่ลงทะเบียนไว้ (C1 หรือแท็บผู้ใช้งานในชีต) คือการสร้างบัญชีใหม่ ถ้าปิดไว้จะเข้าไม่ได้และขึ้น "Signups not allowed"
    * ระบบยังปลอดภัย เพราะรับเฉพาะอีเมล @nu.ac.th และคนที่ไม่ได้ลงทะเบียนจะไม่ได้สิทธิ์ใด ๆ จนผู้ดูแลกำหนด
    * คู่มือ Deploy ฉบับเก่าข้อ 1.3 ที่ให้ปิดสวิตช์นี้ ใช้กับการเข้าด้วยรหัสผ่านเท่านั้น
* **Email:** เปิดไว้ได้ ใช้เป็นช่องทางสำรองสำหรับผู้ดูแล

### 4.3 Google Cloud (ทำเฉพาะเมื่อยังไม่เคยตั้ง หรือย้ายโปรเจกต์ Supabase)

1. https://console.cloud.google.com → โปรเจกต์ของระบบ → **APIs & Services → Credentials**
2. เลือก OAuth Client แบบ **Web application** ในช่อง **Authorized redirect URIs** ต้องมีตรงทุกตัวอักษร

   ```
   https://<รหัสโปรเจกต์>.supabase.co/auth/v1/callback
    ```

3. **OAuth consent screen** แนะนำให้ตั้ง User type เป็น **Internal** (เฉพาะบัญชี @nu.ac.th)
4. นำ Client ID และ Client Secret ไปใส่ใน Supabase ตามข้อ 4.2 ห้ามส่ง Client Secret ทางแชต

## ส่วนที่ 5 — ตรวจ Vercel

**ถ้ายังใช้โปรเจกต์ Supabase เดิม (รหัสตรงตามส่วนที่ 1) ไม่ต้องแก้ Vercel** ให้ข้ามไปข้อ 5.3

### 5.1 Environment Variables (Settings → Environment Variables)

| ชื่อ | ค่า | จำเป็น |
|---|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://<รหัสโปรเจกต์>.supabase.co` | ✅ |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Publishable key `sb_publishable_…` หรือ anon key | ✅ |
| `SUPABASE_SERVICE_ROLE_KEY` | Secret key `sb_secret_…` (คัดลอกทั้งหมดรวม `_` ด้วยปุ่มคัดลอก) | ✅ |
| `NEXT_PUBLIC_SSO_PROVIDER` | `google` | ✅ |
| `CRON_SECRET` | ตั้งเอง: a–z A–Z 0–9 ยาว 32–64 ตัว **ห้ามมีสัญลักษณ์** | ✅ (สำหรับงานแจ้งเตือนรายวัน) |

## ส่วนที่ 7 — Google Sheet + Apps Script (จัดการข้อมูลหลัก)

รายละเอียดพร้อมภาพประกอบอยู่ใน `google-sheets/APPS_SCRIPT_GUIDE_TH.pdf` สรุปขั้นตอนได้ดังนี้

1. **สร้างชีต**
    * Google Drive → **+ ใหม่ → อัปโหลดไฟล์** → `NU-Safety-Sheets-Template.xlsx`
    * เปิดด้วย Google ชีต → **ไฟล์ → บันทึกเป็น Google ชีต**
    * ตั้งชื่อ **NU Safety — ข้อมูลหลัก**
2. **ติดตั้งสคริปต์**
    * **ส่วนขยาย → Apps Script** → ลบโค้ดเดิม → วาง `Code.gs` ทั้งหมด → ตั้งชื่อโปรเจกต์ **NU Safety** → **บันทึก**
    * ปิดแท็บ แล้วรีเฟรชชีต รอให้เมนู **NU Safety** ปรากฏ
3. **อนุญาตสิทธิ์ครั้งแรก**
    * กด **ดำเนินการต่อ** → เลือกบัญชี
    * ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง → ไปที่ NU Safety** → **อนุญาต**
4. **ตั้งค่าการเชื่อมต่อ** ที่เมนู **NU Safety → 🔌 ตั้งค่าการเชื่อมต่อ**
    * Project URL: `https://<รหัสโปรเจกต์>.supabase.co`
    * **Publishable key** ห้ามใช้ Secret key (ระบบจะปฏิเสธ)
    * รหัสนำเข้า `nuimp_…` จาก C2
    * ต้องขึ้น ✅ เชื่อมต่อสำเร็จ
5. **กรอกผู้ใช้** ในแท็บ ผู้ใช้งาน (อีเมล @nu.ac.th ชื่อ และตำแหน่ง ในแถวที่เตรียมไว้)
6. **ส่งข้อมูล** ที่เมนู **NU Safety → ⬆️ ส่งทุกแท็บ** ต้องได้ผลประมาณนี้

    | แท็บ | เส้นทาง ก | เส้นทาง ข |
    |---|---|---|
    | หน่วยงาน | สำเร็จ 43 | สำเร็จ 43 ("มีอยู่แล้ว") |
    | อาคารและชั้น | สำเร็จ 204 | สำเร็จ 204 ("อัปเดตแล้ว") |
    | ห้องและพื้นที่ | สำเร็จ 36 | สำเร็จ 36 |
    | จุดตรวจ | สำเร็จ 60 | สำเร็จ 60 |
    | แผนการตรวจ | สำเร็จ 5 | สำเร็จ 5 |
    | ผู้ใช้งาน | เท่าจำนวนที่กรอก | เท่าจำนวนที่กรอก |

7. ถ้ามี ❌ ให้ดูเหตุผลในคอลัมน์ **สถานะการส่ง** แล้วแก้แถวนั้นและส่งใหม่ ระบบส่งเฉพาะแถวที่ยังไม่สำเร็จ
8. ตั้งดึงรายงานอัตโนมัติ (ไม่บังคับ) ที่เมนู **⏰ ดึงรายงานอัตโนมัติทุกเช้า**

## ส่วนที่ 10 — เก็บกวาดและความปลอดภัย

* **GitHub:** ที่เก็บโค้ดเป็นแบบสาธารณะ ควรเปลี่ยนเป็น **Private** ที่ Settings → Danger Zone
    * Vercel แพ็กเกจฟรีอาจอัปเดตเว็บจากที่เก็บโค้ดแบบส่วนตัวขององค์กรไม่ได้ ให้ตรวจหลังเปลี่ยน
* **Vercel:** ลบโปรเจกต์ซ้ำ `nu-safety-inspection-45cb` ถ้ายังมี และห้ามลบ `nu-safety-inspection`
* **Supabase:** ลบโปรเจกต์ที่ไม่ได้ใช้ ซึ่งรหัสไม่ตรงกับ /setup-check โดยตรวจรหัสให้แน่ใจก่อน
* **คีย์และรหัส**
    * ห้ามส่ง Secret key, Client Secret หรือรหัสนำเข้า `nuimp_…` ทางแชตหรืออีเมล
    * ถ้าสงสัยว่ารั่ว
    * Secret key → Supabase → API Keys → สร้างใหม่ แล้วแก้ใน Vercel และ Redeploy
    * รหัสนำเข้า → รัน `select app.revoke_import_keys();` แล้วรัน C2 ใหม่
* **Google Sheet:** แชร์เฉพาะผู้ดูแลระบบ
* **มือถือที่เคยติดตั้งแอปบนหน้าจอหลัก:** ลบไอคอนแล้วติดตั้งใหม่ หลังติดตั้งระบบใหม่

# คู่มือติดตั้งใหม่ทั้งหมด — NU Safety Inspection

คู่มือนี้ใช้เมื่อต้องการ **ล้างข้อมูลเดิมทั้งหมดแล้วเริ่มใหม่** เพื่อไม่ให้ข้อมูลเก่า ข้อมูลตัวอย่าง (Demo) หรือการติดตั้งที่ค้างครึ่งทางมาปะปนกัน

หลังทำครบจะได้ระบบที่มีข้อมูลดังนี้

* หน่วยงาน 43 หน่วยงาน
* อาคาร 204 อาคาร ซึ่งมีเลขอาคาร ประเภท และหน่วยงานเจ้าของครบ
* จุดตรวจพร้อมใช้ของคณะสาธารณสุขศาสตร์ 60 จุด
* ผู้ดูแลระบบที่เข้าสู่ระบบด้วย Google @nu.ac.th

ใช้เวลาประมาณ 30–45 นาที

### วิธีรันไฟล์ .sql (ใช้แบบเดียวกันทุกขั้น)

1. เข้า https://supabase.com/dashboard แล้วคลิกเลือกโปรเจกต์ของระบบ
2. เมนูซ้ายกด **SQL Editor** (ไอคอน `>_`) แล้วกด **+ New query** มุมซ้ายบน **ทุกครั้งที่เริ่มไฟล์ใหม่**
3. เปิดไฟล์ .sql ด้วย Notepad กด **Ctrl+A** (เลือกทั้งหมด) แล้ว **Ctrl+C** (คัดลอก)
4. คลิกในช่องเขียนของ Supabase กด **Ctrl+A** แล้ว **Ctrl+V** (วางทับของเดิม)
5. กดปุ่ม **Run** มุมขวาล่าง (หรือ Ctrl+Enter)
6. ถ้ามีหน้าต่างเตือน "Potential issue detected / destructive operation" ให้กด **Run this query**
7. ดูผลด้านล่างให้ตรงกับที่คู่มือบอก **ก่อน**ไปขั้นถัดไป

> ⚠️ อย่าลากเลือกข้อความบางส่วนก่อนกด Run เพราะ Supabase จะรันเฉพาะส่วนที่เลือก
> ข้อความ **NOTICE** สีเทา เช่น "already exists, skipping" หรือ "drop cascades to …" เป็นเรื่องปกติ ไม่ใช่ error
> ข้อความ **ERROR** สีแดง ให้หยุด แล้วดูส่วนที่ 7 (แก้ปัญหา)

## ส่วนที่ 1 — ยืนยันว่าจะลบโปรเจกต์ Supabase ที่ถูกต้อง

2. ดูบรรทัด **NEXT_PUBLIC_SUPABASE_URL** แล้วจดรหัสโปรเจกต์ไว้

3. ใน Supabase ดูแถบที่อยู่ของเบราว์เซอร์ ต้องเป็น `supabase.com/dashboard/project/`**`abcdxyzw`**`/…` คือรหัสเดียวกัน
    * ถ้าไม่ตรง ให้กดชื่อโปรเจกต์มุมซ้ายบนแล้วเปลี่ยนไปเลือกโปรเจกต์ที่รหัสตรง

## ส่วนที่ 3 — ลบข้อมูลเดิมทั้งหมด (ขั้นที่ 1)

ไฟล์ **`1_RESET_delete_all_data.sql`** จะลบข้อมูลต่อไปนี้ใน**โปรเจกต์ที่เปิดอยู่**

* หน่วยงาน อาคาร จุดตรวจ ผลตรวจ ข้อบกพร่อง การตั้งค่า
* **บัญชีผู้ใช้ทุกคน** รวมผู้ดูแลระบบ และบัญชีตัวอย่าง @demo.example.com
* ภาพถ่ายและผังชั้นที่อัปโหลด

ไฟล์นี้**ไม่ลบ**สิ่งต่อไปนี้

* การตั้งค่า Vercel
* การตั้งค่า Google login ใน Supabase
* API keys

จึง**ไม่ต้องแก้ Vercel**

ขั้นตอน

1. SQL Editor → **+ New query** → วางเนื้อหาไฟล์ `1_RESET_delete_all_data.sql`
2. หาบรรทัดนี้ (อยู่ประมาณบรรทัดที่ 15)

    ```
    v_confirm text := 'ไม่ลบ';    -- แก้ตรงนี้
    ```

    แก้คำว่า `ไม่ลบ` เป็น `ลบทั้งหมด` โดยเก็บเครื่องหมาย `'` ไว้ทั้งสองข้าง ผลที่ได้ต้องเป็น

    ```
    v_confirm text := 'ลบทั้งหมด';    -- แก้ตรงนี้
    ```

3. กด **Run** แล้วยืนยัน **Run this query**
4. **ผลที่ต้องเห็น:** ตารางด้านล่างแสดง `0 | 0 | false`
    * ตารางที่เหลือ = 0
    * บัญชีผู้ใช้ที่เหลือ = 0
    * ยังมี schema_app = false

> ถ้าไม่ได้แก้คำยืนยัน จะขึ้น ERROR "ยังไม่ได้ยืนยัน …" โดยยังไม่มีอะไรถูกลบ ให้แก้แล้วกด Run ใหม่
> ถ้าข้อความแจ้งว่า "ไฟล์ใน Storage ลบด้วย SQL ไม่ได้" ไม่เป็นไร ทำต่อได้เลย ถ้าต้องการลบไฟล์เก่า ให้ไปที่ **Storage** แล้วเปิด bucket `attachments`, `floor-plans`, `branding` ทีละอัน เลือกทั้งหมด แล้วกด **Delete**

### ขั้นที่ 6 — ตั้งผู้ดูแลระบบคนแรก

วางไฟล์ `6_first_admin.sql` แล้วแก้ 3 จุดที่มีคำว่า **แก้ตรงนี้** ก่อนกด Run

```sql
select app.import_user(
    'somsri.k@nu.ac.th',      -- อีเมล @nu.ac.th ของผู้ดูแลระบบ
    'สมศรี ใจงาม',             -- ชื่อที่แสดงในระบบ
    'ผู้ดูแลระบบ',              -- ตำแหน่ง
    'มหาวิทยาลัยนเรศวร', '', 'system_admin') as ผล;
```

* ต้องการผู้ดูแลหลายคน ให้คัดลอกตั้งแต่ `select` ถึง `as ผล;` เพิ่ม แล้วแก้อีเมลและชื่อ
* ไม่ต้องสร้างผู้ใช้ในหน้า Authentication และไม่ต้องตั้งรหัสผ่าน

## ส่วนที่ 5 — ตรวจการตั้งค่าและเข้าสู่ระบบครั้งแรก

### 5.1 ตรวจการตั้งค่าเข้าสู่ระบบใน Supabase (ไม่ถูกลบ ตรวจเพื่อความแน่ใจ)

1. **Authentication → URL Configuration**
    * **Site URL** = `https://nu-safety-inspection.vercel.app`
    * **Redirect URLs** มี `https://nu-safety-inspection.vercel.app/**`
2. **Authentication → Sign In / Providers → Google** ต้องเป็น **Enabled**

### 5.2 ตรวจการเชื่อมต่อจากเว็บ

1. เปิด https://nu-safety-inspection.vercel.app/setup-check แล้วกด **F5**
2. ทุกบรรทัดต้องเป็น ✅ โดยเฉพาะ 3 บรรทัดล่าง
    * อัปเกรดฐานข้อมูล
    * ข้อมูลหน่วยงาน/อาคาร: **อาคาร 204 · จุดตรวจ 60**
    * ไม่มีข้อมูลตัวอย่าง
3. **ไม่ต้อง Redeploy ใน Vercel** เพราะการติดตั้งครั้งนี้เกิดขึ้นในฐานข้อมูลทั้งหมด

### 5.3 ล้างหน้าเว็บเก่าในเครื่อง (สำคัญ: ป้องกันเห็นข้อมูลเก่าค้าง)

* **คอมพิวเตอร์:** เปิดเว็บแล้วกด **Ctrl+Shift+R** (Mac: **Cmd+Shift+R**) หรือเปิดหน้าต่างไม่ระบุตัวตน
* **มือถือที่ติดตั้งแอปไว้บนหน้าจอหลัก:**
    1. ลบไอคอนแอปออก
    2. เปิดเว็บในเบราว์เซอร์ใหม่ แล้วกด "เพิ่มลงหน้าจอหลัก" อีกครั้ง
* ทุกคนที่เคยเข้าระบบเดิมต้อง **เข้าสู่ระบบใหม่** เพราะบัญชีเดิมถูกลบแล้ว

### 5.4 เข้าสู่ระบบครั้งแรก

1. เปิด https://nu-safety-inspection.vercel.app แล้วกด **เข้าสู่ระบบด้วยบัญชี Google ของมหาวิทยาลัย**
2. เลือกอีเมลที่ใส่ในขั้นที่ 6
3. ต้องเห็นชื่อและบทบาท **ผู้ดูแลระบบมหาวิทยาลัย** ที่มุมซ้ายล่าง และมีเมนู **ตั้งค่าระบบ**
4. เปิดเมนู **อาคารและพื้นที่** ต้องเห็นอาคารจัดกลุ่มตามหน่วยงาน รวม **204 อาคาร** และไม่มีกรอบสีแดง

## ส่วนที่ 6 — เก็บกวาดเพื่อไม่ให้สับสน

### 6.1 Vercel

* **ไม่ต้องลบ Deployment เก่า** เพราะไม่ได้เก็บข้อมูล เว็บใช้รายการบนสุดที่เป็น *Current* เสมอ
* ถ้ายังมีโปรเจกต์ซ้ำ `nu-safety-inspection-45cb` ให้ลบเพื่อไม่ให้มีลิงก์เว็บ 2 ลิงก์
    * ทำที่ Vercel → โปรเจกต์นั้น → **Settings → General** → เลื่อนล่างสุด → **Delete Project**
* ห้ามลบโปรเจกต์ **nu-safety-inspection** ซึ่งเป็นตัวจริง

### 6.2 ไฟล์ในเครื่อง

ลบหรือย้ายไฟล์ .sql และ .zip ฉบับเก่าทั้งหมด เช่น `05_…`, `06_…`, `08_…`, NU-Safety-Deploy.zip ไปไว้ในโฟลเดอร์ "เก่า" แล้วใช้เฉพาะชุด **NU-Safety-Install** นี้

### 6.3 โปรเจกต์ Supabase ที่ไม่ได้ใช้ (ถ้ามี)

* ถ้ามีโปรเจกต์อื่นที่**รหัสไม่ตรงกับหน้า /setup-check** และไม่ได้ใช้แล้ว ให้ลบทิ้ง
* ทำที่ Supabase → โปรเจกต์นั้น → **Project Settings → General** → **Delete project**
* ⚠️ ตรวจรหัสโปรเจกต์ให้แน่ใจก่อนลบทุกครั้ง

### 6.4 GitHub

* ที่เก็บโค้ด `occhealth-nu/nu-safety-inspection` เป็นแบบสาธารณะ ควรเปลี่ยนเป็น **Private**
    * ทำที่ Settings → Danger Zone → Change visibility
* Vercel แพ็กเกจฟรีอาจอัปเดตเว็บจากที่เก็บโค้ดแบบส่วนตัวขององค์กรไม่ได้ ให้ตรวจที่ Vercel หลังเปลี่ยน

## ส่วนที่ 8 — หลังติดตั้ง: เพิ่มข้อมูลใช้งานจริง

ใช้ไฟล์ **NU-Safety-Import-Form.xlsx**

1. **ผู้ใช้งาน** (แท็บ ผู้ใช้งาน)
    * มี 51 แถวที่เลือกหน่วยงานและบทบาทไว้แล้ว ให้กรอกอีเมล @nu.ac.th ชื่อ และตำแหน่ง
    * รอจนคอลัมน์ **ตรวจสอบ** ขึ้น "พร้อมนำเข้า"
    * คัดลอกคอลัมน์ **คำสั่ง SQL** เฉพาะแถวที่กรอก แล้วรันใน SQL Editor
    * แจ้งผู้ใช้ให้เข้าด้วย Google ระบบให้สิทธิ์ทันที
2. **จำนวนชั้น** (แท็บ อาคารและชั้น)
    * มี 201 อาคารที่ยังไม่ทราบจำนวนชั้น ระบบสร้าง "ชั้น 1" ไว้ก่อน
    * กรอกจำนวนชั้นจริงในคอลัมน์ F แล้วคัดลอกคอลัมน์ I ของแถวนั้นไปรัน
3. **ยืนยันข้อมูล 5 อาคาร** ที่มีสีชมพูในคอลัมน์ "ต้องยืนยัน" ได้แก่ NEW01, NIC, NUDS01, NUDS02, PHP02 แก้แล้วรันคำสั่งของแถวนั้นซ้ำ
4. **พิกัดอาคารและผังชั้น** ตั้งในเว็บที่ **ตั้งค่า › อาคารและพื้นที่** (มีช่องค้นหาอาคาร)
5. **พิมพ์ QR จุดตรวจ** ที่เมนู **ทะเบียนจุดตรวจ** แล้วนำแท็บ **จุดตรวจเริ่มต้น** ไปเดินยืนยันที่หน้างาน

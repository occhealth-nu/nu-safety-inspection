# นำเข้าข้อมูลหน่วยงาน อาคาร ห้อง และผู้ใช้งาน

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `deploy/06_import_nu_data.sql` | รันครั้งเดียวใน Supabase SQL Editor: เพิ่มหน่วยงาน 43 หน่วยงาน, อาคาร PH1–PH3 ของคณะสาธารณสุขศาสตร์ (ชั้น 1–4) และเครื่องมือนำเข้า |
| `deploy/07_ready_public_health.sql` | ชุดพร้อมใช้ของคณะสาธารณสุขศาสตร์: ห้อง/พื้นที่มาตรฐาน 36 แห่ง (โถงบันไดหนีไฟ ทางเดินหลัก และตู้ควบคุมไฟฟ้า ทุกชั้น), จุดตรวจ 60 จุด (ถังดับเพลิง ไฟฉุกเฉิน ทางหนีไฟ ตู้ไฟ และ Safety Patrol ทุกชั้น) และแผนการตรวจ 5 แผน พร้อมงานตรวจถึงสิ้นปี |
| `docs/import/แบบฟอร์มนำเข้าข้อมูล-NU-Safety.xlsx` | แบบฟอร์มกรอกผู้ใช้งาน ห้อง และอาคารเพิ่มเติม ระบบสร้างคำสั่ง SQL ให้ในคอลัมน์สีเทา |

## ขั้นตอน

1. Supabase → **SQL Editor** → **New query** → วางไฟล์ `deploy/06_import_nu_data.sql` ทั้งไฟล์ → **Run**
   (ต้องรันไฟล์ 01, 02 และ 05 มาก่อนแล้ว) ตารางผลลัพธ์สุดท้ายจะแสดงอาคาร 3 อาคาร อาคารละ 4 ชั้น
   ต่อด้วยไฟล์ `deploy/07_ready_public_health.sql` → **Run** แล้วพิมพ์ QR จุดตรวจได้ที่เมนู **จุดตรวจ**
   จากนั้นพิมพ์แท็บ **จุดตรวจเริ่มต้น** ไปเดินยืนยันที่หน้างาน แล้วแก้ไข เพิ่ม หรือลบในเว็บให้ตรงกับของจริง
2. เปิดไฟล์ Excel แท็บ **ผู้ใช้งาน** แล้วกรอกในช่องสีเหลือง ได้แก่ อีเมล @nu.ac.th, ชื่อ, ตำแหน่ง, faculty, unit และบทบาท
   มีแถวเตรียมไว้ 51 แถวที่เลือกหน่วยงานและบทบาทไว้แล้ว (ดูคอลัมน์ **หน้าที่**) กรอกเพียงอีเมล ชื่อ และตำแหน่ง
   แถวที่ยังไม่มีคนให้ปล่อยว่างไว้ ระบบจะไม่นำเข้า
   ดูให้คอลัมน์ **ตรวจสอบ** ขึ้นว่า “พร้อมนำเข้า”
3. คัดลอกคอลัมน์ **คำสั่ง SQL** เฉพาะแถวที่กรอก ไปวางใน SQL Editor แล้วกด **Run**
4. แจ้งผู้ใช้ให้กด **เข้าสู่ระบบด้วยบัญชี Google ของมหาวิทยาลัย** ระบบจะกำหนดหน่วยงานและบทบาทให้ทันที
5. ห้อง/พื้นที่ (แท็บ **ห้องและพื้นที่**) และอาคารอื่น (แท็บ **อาคารและชั้น**) ทำแบบเดียวกัน

* **faculty** คือสังกัดของผู้ใช้ ส่วน **unit** คือหน่วยงานที่ได้รับสิทธิ์ตามบทบาท ถ้าเว้น unit ว่างไว้ ระบบใช้ค่าเดียวกับ faculty
  ถ้าผู้ใช้คนเดียวมีหลายบทบาท ให้กรอกหลายแถวโดยใช้อีเมลเดิม
* รันคำสั่งซ้ำได้โดยไม่เกิดข้อมูลซ้ำ ถ้าแถวใดผิด SQL Editor จะหยุดและแจ้งเป็นภาษาไทย ให้แก้แถวนั้นแล้วรันใหม่ทั้งชุด
* ดูรายชื่อที่ลงทะเบียนล่วงหน้าได้ด้วยคำสั่ง
  `select email, role, applied_at from user_preassignments order by created_at desc;`
  ถ้า `applied_at` ว่าง แปลว่าผู้ใช้คนนั้นยังไม่เคยเข้าระบบ
* พิกัด GPS และผังชั้นของอาคาร ตั้งในเว็บที่ **ตั้งค่า › อาคารและพื้นที่**
* แก้ข้อมูลต้นทางได้ใน `scripts/build-import-data.py` แล้วรัน `python3 scripts/build-import-data.py` เพื่อสร้างไฟล์ทั้งสองใหม่

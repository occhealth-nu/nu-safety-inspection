# ชุดข้อมูลพร้อม Deploy — NU Safety Inspection

ข้อมูลทั้งหมดผ่านการตรวจความสมบูรณ์แล้ว ประกอบด้วย

* หน่วยงาน 43 หน่วยงาน
* อาคาร 204 อาคาร ซึ่งมีเลขอาคาร ประเภทอาคาร และหน่วยงานเจ้าของครบทุกอาคาร
* ชุดพร้อมใช้ของคณะสาธารณสุขศาสตร์ ได้แก่ จุดตรวจ 60 จุด และแผนการตรวจ 5 แผน
* แบบฟอร์มผู้ใช้งาน 51 แถว ซึ่งกำหนดหน่วยงานและบทบาทไว้แล้ว

## ไฟล์ในชุด

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `deploy/00_check_database.sql` | ตรวจว่าฐานข้อมูลยังขาดอะไร (อ่านอย่างเดียว รันได้ทุกเมื่อ ต้องได้ ✅ ครบ 8 ข้อ) |
| `deploy/01_install_database.sql` | สร้างฐานข้อมูลทั้งหมด **เฉพาะโปรเจกต์ Supabase ใหม่** |
| `deploy/02_starter_data.sql` | มหาวิทยาลัย (หน่วยงานราก) + แบบตรวจ 8 หมวด + ประเภทจุดตรวจ **เฉพาะโปรเจกต์ใหม่** |
| `deploy/05_upgrade_building_locations.sql` | อัปเกรดฐานข้อมูลเดิม (ผังชั้น หมุด พิกัด) **เฉพาะระบบที่ใช้อยู่แล้ว** |
| `deploy/06_import_nu_data.sql` | หน่วยงาน 43 หน่วยงาน + อาคาร 204 อาคาร + เครื่องมือนำเข้า |
| `deploy/07_ready_public_health.sql` | ห้อง/พื้นที่ จุดตรวจ แผนการตรวจ และงานตรวจของคณะสาธารณสุขศาสตร์ (PHP01–PHP03) |
| `deploy/08_remove_demo_data.sql` | ลบข้อมูลตัวอย่าง EN1/SC2/QS และบัญชี @demo.example.com (ถ้ามี) |
| `docs/import/แบบฟอร์มนำเข้าข้อมูล-NU-Safety.xlsx` | แบบฟอร์มผู้ใช้งาน, อาคารและชั้น (204 อาคาร), ผลตรวจข้อมูลอาคาร, ห้อง และจุดตรวจเริ่มต้น |
| `data/nu-buildings.csv` | ทะเบียนอาคารที่ตรวจแล้ว (รวมโซนไว้อ้างอิง) |
| `data/nu-buildings-changes.csv` | บันทึกการแก้ไขข้อมูลอาคารทั้ง 73 จุด เทียบกับไฟล์ต้นฉบับ |

วิธีรันทุกไฟล์ทำแบบเดียวกัน

1. เข้า Supabase แล้วเปิด **SQL Editor**
2. กด **+ New query**
3. เปิดไฟล์ด้วย Notepad แล้วกด **Ctrl+A** และ **Ctrl+C**
4. กลับไปที่ Supabase แล้วกด **Ctrl+V** จากนั้นกด **Run**
5. ถ้ามีหน้าต่างเตือน ให้กด **Run this query**

ข้อความ NOTICE … already exists, skipping เป็นเรื่องปกติ ทุกไฟล์รันซ้ำได้โดยไม่เกิดข้อมูลซ้ำ

## ทางเลือก ข: ติดตั้งใหม่ทั้งหมด (โปรเจกต์ Supabase ใหม่)

1. สร้างโปรเจกต์และตั้งค่า Vercel ตาม `docs/DEPLOY_GUIDE.md` ขั้นที่ 1–3
   * ต้องเปลี่ยน Environment Variables ใน Vercel เป็นค่าของโปรเจกต์ใหม่
   * ใน Supabase ที่ Authentication → URL Configuration ให้ใส่ Site URL `https://nu-safety-inspection.vercel.app`
   * ตั้งค่า Google provider ใหม่ด้วย
2. รันไฟล์ตามลำดับ: `01` → `02` → `06` → `07` → `00` (ไม่ต้องรัน 05 และ 08)
3. ตั้งผู้ดูแลระบบคนแรกด้วยอีเมล @nu.ac.th (ไม่ต้องตั้งรหัสผ่าน) แก้อีเมลและชื่อในคำสั่งด้านล่าง แล้วกด Run

   ```sql
   select app.import_user('ชื่อ.น@nu.ac.th', 'ชื่อ นามสกุล', 'ผู้ดูแลระบบ', 'มหาวิทยาลัยนเรศวร', '', 'system_admin');
   ```

4. เปิดเว็บแล้วกด **เข้าสู่ระบบด้วยบัญชี Google ของมหาวิทยาลัย** ระบบจะให้สิทธิ์ผู้ดูแลระบบทันที

## หลัง Deploy: เพิ่มผู้ใช้งานและเติมข้อมูลอาคาร

* **ผู้ใช้งาน** (แท็บ ผู้ใช้งาน)
  * กรอกอีเมล @nu.ac.th ชื่อ และตำแหน่งในแถวที่เตรียมไว้
  * คัดลอกคอลัมน์ **คำสั่ง SQL** ไปวางใน SQL Editor แล้วกด **Run**
  * ผู้ใช้เข้าด้วย Google แล้วได้สิทธิ์ทันที
* **จำนวนชั้น** (แท็บ อาคารและชั้น)
  * มี 201 อาคารที่ไฟล์ต้นฉบับยังไม่ระบุจำนวนชั้น ระบบสร้าง "ชั้น 1" ไว้ก่อน
  * เติมจำนวนชั้นจริงในคอลัมน์ F แล้วคัดลอกคอลัมน์ I ของแถวที่แก้ไปรัน ระบบจะเพิ่มชั้นที่ขาดให้
* **พิกัดอาคารและผังชั้น** ตั้งในเว็บที่ **ตั้งค่า › อาคารและพื้นที่** ช่องค้นหารองรับรหัส ชื่อ เลขอาคาร และหน่วยงาน
* **ประเด็นที่ต้องให้หน่วยงานยืนยัน** มี 5 อาคาร ดูได้ในแท็บ อาคารและชั้น (คอลัมน์ "ต้องยืนยัน" สีชมพู)
  * NEW01: หน่วยงานเจ้าของในไฟล์ระบุ "ส่วนกลาง" ระบบกำหนดให้กองอาคารสถานที่ไว้ชั่วคราว
  * NIC: เจ้าของระบุเป็นคณะมนุษยศาสตร์
  * NUDS01, NUDS02: เจ้าของระบุเป็นคณะศึกษาศาสตร์ แต่ระบบมีหน่วยงานโรงเรียนสาธิตแยกไว้แล้ว
  * PHP02: จับคู่กับ "อาคารสุขวิทยาสถิตย์" จากไฟล์ก่อนหน้า

  ถ้าต้องแก้ ให้แก้ในแท็บ **อาคารและชั้น** แล้วรันคำสั่งของแถวนั้นซ้ำ


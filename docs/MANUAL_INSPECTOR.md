# คู่มือผู้ตรวจ (ใช้งานบนมือถือ)

## เริ่มต้น
1. เปิดระบบในเบราว์เซอร์มือถือ → เข้าสู่ระบบ
2. (แนะนำ) เมนูเบราว์เซอร์ → “เพิ่มลงในหน้าจอหลัก” เพื่อเปิดเหมือนแอป
3. ปุ่มกลางด้านล่าง **สแกน** = เริ่มตรวจ

## ตรวจด้วย QR Code
1. กด **สแกน** → “เปิดกล้องสแกน QR” → หันกล้องไปที่ป้าย QR (ต้องอนุญาตการใช้กล้อง)
   - กล้องเปิดไม่ได้: พิมพ์ **รหัสจุดตรวจ** ที่อยู่ใต้ QR ในช่องค้นหา
2. หน้าจุดตรวจแสดงตำแหน่ง งานที่ถึงรอบ และข้อบกพร่องค้าง → กด **เริ่มตรวจตามงานที่ถึงรอบ**
   - ถ้าไม่มีงานถึงรอบ จะเป็น “เริ่มตรวจ (นอกรอบ)”
   - “ไม่มีสิทธิ์” = จุดตรวจอยู่นอกหน่วยงานที่คุณได้รับมอบหมาย

## ตรวจจากรายการงาน
เมนู **เริ่มตรวจ** → “งานที่ต้องตรวจของฉัน” (เรียงตามวันครบกำหนด, งานเกินกำหนดมีไอคอนเตือนสีแดง) → แตะงาน

## บันทึกผลรายข้อ
- กดปุ่มใหญ่ **ผ่าน / ไม่ผ่าน / ไม่เกี่ยวข้อง**
- **ไม่เกี่ยวข้อง** → ต้องระบุเหตุผล (ข้อนี้ไม่นับในคะแนน)
- **ไม่ผ่าน** → ต้องกรอก
  - รายละเอียดข้อบกพร่อง
  - ระดับความเร่งด่วน (ต่ำ / ปานกลาง / สูง / วิกฤต) — สูงและวิกฤตจะแจ้งเตือนผู้ดูแลทันทีหลังส่ง
  - ภาพหลักฐาน (กล้องหลังเปิดอัตโนมัติ; ระบบย่อภาพให้) — หาก **ถ่ายไม่ได้เพราะไม่ปลอดภัย/พื้นที่ห้ามถ่ายภาพ** ให้กรอกเหตุผลแทน
- แถบล่างแสดง “ตอบแล้ว x/y · คะแนน” และสถานะการบันทึกร่าง

## ฉบับร่างและเครือข่าย
- ทุกครั้งที่แก้ไข ระบบเก็บสำเนาไว้ **ในเครื่อง** และบันทึกร่างเข้าระบบอัตโนมัติทุก 20 วินาทีเมื่อออนไลน์ หรือกด 💾 **บันทึกร่าง**
- แถบสีแดงด้านบน “ไม่มีการเชื่อมต่อเครือข่าย” = ข้อมูลยังอยู่ในเครื่อง **ยังไม่ถูกส่ง**
- ระบบ **ยังไม่รองรับการส่งผลแบบออฟไลน์** — เมื่อมีสัญญาณ เปิดหน้าเดิม (หรือ เริ่มตรวจ › ฉบับร่างที่ยังไม่ส่ง) แล้วกดส่ง
- ภาพต้องอัปโหลดขณะออนไลน์

## ส่งผลตรวจ
1. กด **ส่งผลตรวจ** — ถ้าข้อมูลไม่ครบ ระบบเลื่อนไปยังข้อที่ต้องแก้และแสดงสาเหตุ
2. รอข้อความ “กำลังส่งผลตรวจ… กรุณารอการยืนยันจากระบบ”
3. **สำเร็จจริงเมื่อเห็นหน้า “ระบบบันทึกผลตรวจเรียบร้อยแล้ว”** พร้อมจำนวนข้อบกพร่องที่สร้าง
4. เครือข่ายหลุดระหว่างส่ง: กดส่งอีกครั้งได้อย่างปลอดภัย ระบบจะไม่บันทึกซ้ำ
5. ส่งแล้วแก้ไขไม่ได้ (หากผิดพลาด แจ้งผู้ดูแลหน่วยงาน)

## หลังส่ง
- ข้อไม่ผ่านกลายเป็น “ข้อบกพร่อง” เลขที่ `NC-25xx-xxxxx` เพื่อติดตามแก้ไข
- ประวัติการตรวจดูได้ที่หน้าจุดตรวจ › ประวัติการตรวจ
